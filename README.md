# Interactive Excel Project Monitoring Dashboard

This project is an interactive project monitoring dashboard built using **Excel, VBA, and PivotTables**.

It was originally developed as a real project, and I decided to share it after anonymizing the data and preserving the dashboard structure and functionality.

## Features
- Dynamic search with suggestions
- Automated filtering
- Drill-down project details
- KPI monitoring
- Custom progress visuals
- Application-like user experience inside Excel

## Tools Used
- Microsoft Excel
- VBA
- PivotTables
- GETPIVOTDATA
- ActiveX Controls
- Charts and Shapes

## Project Structure
- `Project_Monitoring_Dashboard.xlsm` → main dashboard file
- `screenshots/` → project screenshots
- `README.md` → project documentation

## Notes
The data used in this published version has been anonymized to protect confidentiality.
