# Project Overview

This project is an interactive project monitoring dashboard built using Excel, VBA, and PivotTables.

It was originally developed as a real project, then later anonymized and prepared for publishing while preserving the original structure and functionality.

## Purpose

The goal of this project was to transform Excel from a traditional spreadsheet into an interactive monitoring tool that helps users track projects in a more efficient and user-friendly way.

## What the dashboard covers

The dashboard helps in monitoring:
- projects
- contracts
- invoice values
- executed work values
- progress percentages
- project details by selection

## Core idea

The solution was designed as a layered Excel application:

- Data Layer  
  The raw and prepared project data stored in structured tables

- Logic Layer  
  PivotTables, formulas, and calculated outputs used to feed the dashboard

- Presentation Layer  
  A custom-designed dashboard interface with search, filters, KPIs, and detail views

## Main capabilities

- Dynamic search with suggestions
- Automated filtering
- Drill-down project details
- KPI tracking
- Custom progress visuals
- Interactive Excel-based user experience

## Publishing note

All sensitive data and names were anonymized before publishing this version of the project.
