# UI / UX Design Inside Excel

One of the strongest parts of this project is that it was not designed as a traditional spreadsheet.

Instead, the goal was to create an experience inside Excel that feels closer to a small interactive application.

## Design direction

The dashboard was designed to reduce the feeling of working with raw sheets and cells.

The focus was on building a cleaner interface that allows the user to:
- navigate more easily
- understand key metrics quickly
- interact with filters and details smoothly
- focus on decisions instead of raw data

## Front-end dashboard approach

The visible dashboard sheet acts as a presentation layer rather than a calculation sheet.

Instead of exposing raw formulas and pivot outputs to the user, the interface presents:
- KPI cards
- buttons and clickable elements
- search controls
- progress visuals
- detail sections
- grouped visual components

This improves readability and gives the dashboard a more polished feel.

## Application-like behavior

The dashboard was designed to behave more like a lightweight application than a static report.

This includes:
- interactive search behavior
- clickable controls
- dynamic detail views
- hidden support logic in background sheets
- visual separation between input, analysis, and output

## Visual hierarchy

The interface uses visual hierarchy to guide the user through the dashboard.

Important values are given more visibility through:
- placement
- shape size
- section grouping
- labels
- icons
- progress visuals

This helps the user understand the dashboard faster.

## Use of shapes and layout

The project uses shapes and layout components to structure the dashboard visually.

Examples include:
- rounded containers
- grouped elements
- icons
- separate sections for KPIs and details
- custom visual blocks instead of plain Excel ranges

This makes the workbook more engaging and easier to explore.

## Navigation experience

The dashboard is designed so the user can move through information using interface elements rather than relying only on Excel sheet tabs.

This improves usability, especially for users who are not expected to interact directly with raw backend sheets.

## Why this matters

A lot of Excel dashboards are technically correct but difficult to use.

In this project, UI and UX were treated as part of the solution itself, not as a secondary detail.

This makes the dashboard more practical, more understandable, and more professional as a final product.

## Technical note

From the workbook structure, the dashboard includes a large number of shapes, visual components, images, and interactive controls that support a presentation-first design approach inside Excel.
