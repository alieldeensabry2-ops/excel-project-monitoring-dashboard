# Rebuild Step 5: UserForms

UserForms are used to display detailed views.

## Main forms

- Area_Dash
- Contracts_Dash
- IND_Area

## Area_Dash

Used for:
- project details
- KPIs
- labels
- charts

## Contracts_Dash

Used for:
- contract details
- company info
- progress tracking

## IND_Area

Used for:
- alternative navigation or area-based views

## Design principles

- use dynamic labels
- hide empty elements
- control visibility using VBA
- use scrollbars for long content

## Why this matters

UserForms separate detail views from the main dashboard.
